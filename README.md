# MEgham-new-website-

A complete modern redesign and development for **Megham Restaurant & Bakery** — combining fine rooftop dining, an artisan patisserie & custom cake studio, and a premier celebration destination in Haridwar, Uttarakhand.

## ✨ Features
- **Modern Brand Palette:** Warm beige (`#E8D8C3`), creamy white (`#FFF9F0`), chocolate brown (`#4A2E23`), deep espresso (`#2B1B16`), muted golden (`#C5A46D`), and soft caramel (`#B8875B`).
- **Multi-Page Architecture:**
  - `/` — Comprehensive Home Page with all highlights
  - `/story` — Our Story, philosophy & pure vegetarian integrity
  - `/menu` — Complete rooftop menu with dietary tags & WhatsApp ordering
  - `/bakery` — Artisan Patisserie Studio & custom cake consultation
  - `/celebrations` — Event packages for birthdays, anniversaries, and family banquets
  - `/gallery` — Editorial magazine-style photo exhibition with lightbox
  - `/instagram` — 9:16 vertical video Reels & social moments
  - `/contact` — Location, hours, directions & 6 quick-action buttons
- **Dual Logo Support:** Light logo on dark backgrounds, dark logo on light backgrounds, with graceful typography insignia fallback.
- **Interactive Modals:** Table Reservation, Custom Cake Order, and Celebration Planner with instant pre-formatted WhatsApp transmission.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
